# Java Standards

**Invoke `frie-core:engineering-patterns` first.** It holds every rule that is the same in all languages: precedence, naming, signatures, absence, control flow, comments, design, testing, suppressions, and the done checklist. This skill adds only how Java expresses those rules in its own idioms, and never restates them.

Read `references/java.md` **before** the first edit of a `*.java` file or a Java project's Gradle build, not as a check afterward, and read it for test files too, since it holds the test conventions. It ends with canonical shapes. Copy those rather than re-deriving them from the rules.
